# Lojinha da Tuca — versão Web

Versão web inicial baseada na aplicação desktop V101.

## Como usar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `app.js` e a pasta `assets`.
3. Em **Settings → Pages**, escolha a branch principal e a pasta `/root`.
4. Abra o endereço fornecido pelo GitHub Pages.

## Dados
Esta primeira versão usa `localStorage` do navegador. Os dados ficam neste navegador/dispositivo.
Use **Exportar backup** para guardar uma cópia JSON e **Importar backup** para restaurar.

## Módulos
Produtos, Clientes, Vendas, Contas a Receber, Fornecedores, Contas a Pagar, Saques, Vendas Finalizadas e Relatórios.

Próxima etapa recomendada: banco de dados online para permitir acesso aos mesmos dados pelo celular e por outros computadores.
